This Week 4 report documents the system integration and final testing stage of the Smart Environment Monitoring and Alert System. The work combines the firmware and interface decisions developed in the earlier weeks into one integrated ESP32 design. The integrated model includes the DHT22 temperature and humidity sensor, an LDR connected to the ESP32 ADC for relative light-level measurement, an SSD1306 OLED connected through I2C, a buzzer alert output, and UART/USB serial diagnostics. The Week 3 non-blocking timing scheduler and sensor-error handling are retained in the final firmware.

The integration strategy maps each module to a clear interface and keeps all monitoring functions inside a 2-second scheduled cycle. The system validates DHT22 readings before they enter the threshold logic and uses inclusive warning boundaries of 35.0 C for temperature, 80.0 % RH for humidity, and a prototype low-light ADC boundary of 1200. A deterministic software-level integration harness was used to verify normal operation, boundary conditions, invalid sensor handling, scheduler timing, and cycle count, with 7 of 7 core logic checks passing. The report also documents integration challenges such as mixed interfaces, timing interference, error propagation, alert-state handling, display failures, and the limitation of uncalibrated LDR values. Direct simulator evidence from the earlier ESP32 + DHT22 stage is retained, while the full Week 4 model is presented as an implementation-ready integrated configuration rather than an unsupported physical measurement claim.
